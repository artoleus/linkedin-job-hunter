🔄 Backup & Restore

Move your settings, applications and connection history to another computer

Settings

Saves your target roles, keywords, limits, salary and work-type preferences, and your application answers, to a file you can import on another computer.

The file includes your auto-fill name, email and phone number, so keep it private.

Moving to another computer

  1. Here, export your settings, then use Export CSV on the Applications and Connection Analytics pages (with filters set to show everything).
  2. On the new computer, install the extension and open this page from the popup.
  3. Import the settings file here, then use Import CSV on the Applications and Connection Analytics pages. Anything you already have is skipped, so importing the same file twice is safe.
